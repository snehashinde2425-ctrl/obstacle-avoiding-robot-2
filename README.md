# Obstacle Avoiding Robot

## Project Overview
An Arduino-based obstacle avoiding robot that detects obstacles using an ultrasonic sensor and automatically changes its direction to avoid collisions.

## Components Used
- Arduino Uno
- Ultrasonic Sensor
- Motor Driver
- DC Motors
- Robot Chassis
- Battery
- Connecting Wires

## Working
The ultrasonic sensor continuously measures the distance between the robot and an obstacle. The Arduino processes the sensor data and controls the motors accordingly. When an obstacle is detected within a certain distance, the robot changes its direction to avoid the obstacle.

## Technologies Used
- Arduino
- Embedded C/C++
- Ultrasonic Sensor
- Motor Control

## Features
- Automatic obstacle detection
- Automatic direction change
- Ultrasonic distance measurement
- Motor control using Arduino
